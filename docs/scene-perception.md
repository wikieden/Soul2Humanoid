## 1. 场景感知的核心挑战

具身智能的场景感知不同于传统计算机视觉，需要解决以下关键问题：

| 挑战维度 | 具体问题 | 技术要求 |
|---------|---------|---------|
| **3D 空间理解** | 从 2D 图像推断深度、形状、遮挡关系 | 占用网络、立体视觉、点云处理 |
| **语义理解** | 识别物体类别、功能、可操作性 | 视觉-语言模型、语义分割 |
| **时序理解** | 追踪物体状态变化、预测未来 | 世界模型、记忆机制、因果推理 |
| **多模态融合** | 整合视觉、触觉、本体感觉 | 跨模态 Transformer、特征对齐 |
| **实时性** | 在有限算力下实现高频感知 | 模型压缩、异步推理、边缘部署 |

## 2. 各公司技术方案详解

### 2.1 Figure AI — Helix 三层架构

**核心架构**: System 0 + System 1 + System 2

```
System 2 (VLM)     → 语义推理、任务规划 (7-9 Hz)
    ↓
System 1 (VLA)     → 视觉运动策略 (200 Hz)
    ↓
System 0 (Locomotion) → 运动控制 (1 kHz)
```

**场景感知关键技术**:

| 技术模块 | 功能 | 实现细节 |
|---------|------|---------|
| **立体视觉** | 深度感知 | 双目相机 + 多尺度特征提取，吞吐量提升 60% |
| **视觉记忆** | 时序上下文 | 短期视觉记忆模块，组合近期视频帧特征 |
| **力反馈融合** | 触觉感知 | 指尖传感器（3g 精度）+ 力反馈输入策略网络 |
| **在线自校准** | 跨机器人泛化 | 视觉本体感觉模型，从图像估计末端执行器 6D 位姿 |

**关键突破**:
- **System 0**: 用 1000+ 小时人类运动数据训练的神经网络，替代 109,504 行 C++ 代码
- **视觉记忆**: 条形码定向任务成功率从基线提升至 95%，机器人能"记住"已检查过的包裹侧面
- **多机器人协作**: 两台 Helix-02 机器人无需共享规划器，仅从运动推断对方意图

**数据来源**: [Figure AI Helix 技术报告](https://www.figure.ai/news/helix), [Helix 02 架构解析](https://medium.com/@geedhpruthvi/inside-figures-helix-02-architecture-7330ca5eb268)

### 2.2 1X Technologies — World Model + Redwood VLA

**核心架构**: World Model (虚拟仿真器) + Redwood VLA (端到端控制)

**World Model 技术细节**:

| 能力 | 描述 | 应用场景 |
|------|------|---------|
| **多未来预测** | 从同一初始图像序列，预测不同动作提案的多种未来 | 动作评估、规划 |
| **物理交互预测** | 刚体动力学、物体掉落效果、部分可观测性 | 操作规划 |
| **可变形物体** | 窗帘、衣物、 articulated objects (门、抽屉) | 家庭环境操作 |
| **评估基准** | 解决 1000 个任务的评估难题 | 模型迭代验证 |

**Redwood VLA 架构**:

```
输入:
  - 预训练语言嵌入 (语言指令)
  - 视觉 Transformer 特征 (图像)
  - 本体感觉嵌入 (关节位置 + 力)
      ↓
Transformer Blocks (多层)
      ↓
潜在表示向量
      ↓
Diffusion Policy 解码
      ↓
EVE / NEO 动作
```

**关键特性**:
- **跨本体架构**: 同一模型控制 EVE 和 NEO 两种平台
- **全身控制**: 首个同时控制运动 + 操作的 VLA，支持支撑和倾斜行为
- **移动双臂操作**: 在移动中精确操作物体
- **板载运行**: 完全在 NEO 的嵌入式 GPU 上运行

**数据来源**: [1X World Model](https://www.1x.tech/discover/1x-world-model), [Redwood AI](https://www.1x.tech/discover/redwood-ai)

### 2.3 Tesla Optimus — FSD 技术迁移

**核心架构**: 统一 AI 架构 (Unified AI Architecture)

**关键洞察**: Tesla 将自动驾驶 (FSD) 的场景感知技术直接迁移到人形机器人，采用**完全相同的神经网络架构**。

**Occupancy Network (占用网络)**:

| 技术特性 | 实现细节 | 优势 |
|---------|---------|------|
| **体素化 3D 表示** | 将空间划分为 3D 体素 (默认 33cm，近处 10cm) | 自适应分辨率，平衡精度与计算 |
| **占用状态预测** | 每个体素预测是否被有质量物体占据 | 无需 LiDAR，纯视觉 3D 理解 |
| **占用流 (Occupancy Flow)** | 预测移动体素的速度向量 | 动态物体追踪 |
| **语义标注** | 区分车辆、建筑、路缘等 | 优先级处理，聚焦关键物体 |
| **部分占用** | 将占据空间细分为子体素 | 精确识别弯曲物体形状 |

**视觉 Transformer 融合**:
- 2D 图像特征 → Transformer 空间注意力 → 统一 3D 表示
- 当前 3D 空间 + 历史时间戳表示 → 时空融合
- 三线性插值估计体素内任意点的占用状态

**GPS 死区解决方案** (专利 US20240185445A1):
- **关键图像特征**: 识别环境中的独特视觉锚点 (出口标志、灭火器、墙壁裂缝)
- **视觉定位**: 追踪关键特征在连续帧中的运动，数学计算自身位置
- **无需外部依赖**: 不依赖 GPS、LiDAR 或预建地图

**统一架构优势**:
- **单一连续过程**: 高层推理 + 低层控制不分离，避免接口故障点
- **梯度流畅传播**: 边缘场景的错误信号能有效传递到所有层
- **硬件软件紧耦合**: AI5 芯片 (40× 快于 AI4) 专为神经网络工作负载优化

**数据来源**: [Tesla FSD 专利解析](https://www.notateslaapp.com/news/3864), [统一 AI 架构](https://gearmusk.com/2026/03/26/tesla-unified-ai-brain/)

### 2.4 Physical Intelligence — π0 系列 + MEM 记忆

**核心架构**: VLA Foundation Model + Multi-Scale Embodied Memory

**π0 系列演进**:

| 版本 | 时间 | 场景感知突破 |
|------|------|-------------|
| **π0** | 2024.10 | 首个跨本体通用策略，Flow Matching 动作生成 |
| **FAST** | 2025.01 | DCT+BPE 动作 Tokenization，5× 训练加速 |
| **π0.5** | 2025.04 | 开放世界泛化，新环境零样本 |
| **π*0.6** | 2025.11 | 在线 RL 学习，Recap 算法 |
| **MEM** | 2026.03 | 多尺度具身记忆，15 分钟长程任务 |
| **π0.7** | 2026.04 | 可组合泛化，涌现能力 |

**MEM (Multi-Scale Embodied Memory) 技术详解**:

```
短期记忆 (Short-Term):
  - 基于高效视频编码器的帧级历史
  - 保留近期原始观测细节
  - 适用于精细动作回顾

长期记忆 (Long-Term):
  - 基于自然语言的抽象概念
  - 文本形式记录关键事件和状态
  - 例: "已将锅盖放在灶台左侧"

主动推理机制:
  - 动态选择需要记忆的内容
  - 同时进行高层子任务规划
  - 决定"做什么" + "记住什么"
```

**核心能力**:
- **15 分钟长程任务**: 打扫整个厨房、制作烤奶酪三明治
- **部分可观测环境**: 物体不在视野中时仍能记住位置
- **上下文自适应**: 根据历史经验动态调整策略，避免重复错误

**Human→Robot Transfer (2025.12)**:
- 发现人类视频到机器人任务的迁移能力在大规模 VLA 中**涌现**
- 利用第一人称人类视频 (ego-centric data) 作为额外训练数据源
- 提供约 **2× 数据效率提升**

**数据来源**: [PI 官方博客](https://www.pi.website/blog), [MEM 论文](https://www.pi.website/download/Mem.pdf)

## 4. 关键技术趋势

### 4.1 从模块化到端到端

**传统方法**: 感知 → 规划 → 控制 (分离模块)  
**现代趋势**: 像素 → 动作 (端到端神经网络)

| 阶段 | 代表 | 特点 |
|------|------|------|
| **模块化** | 传统机器人 | 可解释，但接口故障点 |
| **混合** | Figure Helix | 分层但紧耦合 |
| **统一** | Tesla Optimus | 单一连续过程，控制粒度为参数 |

### 4.2 世界模型的崛起

**核心价值**: 在虚拟环境中评估动作，无需真实试错

| 公司 | World Model 用途 | 技术路线 |
|------|-----------------|---------|
| **1X** | 多未来预测，动作评估 | 视频生成模型 |
| **Tesla** | 占用流预测，动态物体追踪 | Transformer 时空融合 |
| **NVIDIA** | 合成数据生成 (Cosmos) | 扩散模型 + 物理仿真 |
| **PI** | 隐含在 VLA 中 | 大规模预训练 |

### 4.3 记忆机制成为标配

**长程任务瓶颈**: 不是技能本身，而是如何部署技能

| 记忆类型 | 实现 | 优势 |
|---------|------|------|
| **短期视觉** | 视频帧缓冲 | 精细动作回顾 |
| **长期语义** | 自然语言摘要 | 压缩历史，避免因果混淆 |
| **检索增强** | 向量数据库 | 可扩展，支持查询 |

### 4.4 人类视频数据价值凸显

**关键发现**: 人类视频到机器人任务的迁移能力在大规模模型中**涌现**

| 公司 | 人类视频使用 | 效果 |
|------|-------------|------|
| **PI** | 第一人称视频预训练 | 2× 数据效率提升 |
| **NVIDIA** | 20K 小时 EgoScale | 跨本体泛化提升 |
| **Figure** | 1000+ 小时运动数据 | System 0 替代 C++ 代码 |

## 5. 开放问题与未来方向

### 5.1 当前局限

| 问题 | 描述 | 影响 |
|------|------|------|
| **部分可观测性** | 物体被遮挡时状态不确定 | 操作失败，规划错误 |
| **动态物体** | 移动物体追踪和预测 | 碰撞风险，路径规划困难 |
| **长尾场景** | 罕见物体和情况 | 泛化失败，需要人工干预 |
| **计算效率** | 高频感知需要大量算力 | 边缘部署挑战，能耗问题 |

### 5.2 未来方向

| 方向 | 技术路线 | 预期突破 |
|------|---------|---------|
| **神经辐射场 (NeRF/3DGS)** | 隐式 3D 表示 | 高质量新视角合成，精细几何 |
| **基础世界模型** | 大规模视频预训练 | 通用物理理解，零样本迁移 |
| **主动感知** | 信息增益驱动探索 | 高效减少不确定性 |
| **多机器人协作感知** | 分布式场景图融合 | 大场景覆盖，视角互补 |

## 6. 总结

具身智能的场景感知正在经历从**模块化**到**端到端**、从**瞬时感知**到**长程记忆**、从**单一模态**到**多模态融合**的范式转变。

**关键洞察**:

1. **统一架构是趋势**: Tesla 的统一 AI 架构避免了接口故障点，梯度流畅传播
2. **记忆机制是长程任务的关键**: PI 的 MEM 支持 15 分钟任务，NVIDIA 的 ReMEmbR 支持小时级上下文
3. **人类视频数据价值巨大**: 多家公司的研究表明，人类视频预训练能显著提升机器人泛化能力
4. **World Model 支持规划**: 1X 的 World Model 允许在虚拟环境中评估动作，减少真实试错
