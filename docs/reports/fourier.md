## 产品：GR-2 通用人形机器人

### 硬件规格

| 参数 | 规格 |
|------|------|
| 高度 | 1.75 m |
| 重量 | 63 kg |
| 自由度 | 53（含 12-DoF 灵巧手） |
| 关节峰值扭矩 | 436 N·m |
| 步行速度 | 5 km/h |
| 单臂负载 | ≈3 kg |
| 电池 | ≈950 Wh，约 2 小时续航，热插拔可换 |
| 充电 | 约 2 小时 |
| 材质 | 铝合金 + 工程塑料 |

### 核心组件

| 组件 | 说明 |
|------|------|
| **FSA 2.0 执行器** | 7 款不同型号人形专用执行器，双编码器精度翻倍，峰值扭矩超 380 N·m |
| **12-DoF 灵巧手** | 6 阵列触觉传感器，实时感知力与形状 |
| **计算平台** | 14 核 CPU（基础）+ 可选 275 TOPS AI 加速模块（Jetson Orin） |

### AI 与软件
- **Fourier Toolkit**：支持 NVIDIA Isaac Lab、ROS、Mujoco、Webots
- 提供机器视觉、路径规划、力控反馈等算法模块 SDK
- 基于 Linux 的开发环境

## 技术路线

| 能力维度 | 当前水平 |
|---------|---------|
| 运动控制 | 53 DoF 全身控制，5 km/h 稳定行走 |
| 灵巧操作 | 12-DoF 手 + 触觉感知阵列 |
| AI 智能 | 半自主运行，视觉 SLAM，依赖外部框架进行 AI 开发 |
| VLA 模型 | **不自研**，提供开放平台供第三方/研究者部署 VLA 策略 |

> 傅利叶的核心定位是**开放的具身智能硬件平台**，而非自研 AI 模型的公司。

## 商业化定位

### 核心场景
| 场景 | 说明 |
|------|------|
| **医疗康复** | 唯一专为医疗/康复设计的人形机器人，源于傅利叶的康复医疗基因 |
| **学术研究** | ROS 开放平台，广泛用于高校和研究所的具身智能研究 |
| **工业制造** | 实验性应用，如质量检测、轻型装配 |
| **接待服务** | 导览、咨询等场景 |

### 差异化优势
1. **医疗康复基因**：深厚的临床级康复设备设计经验
2. **FSA 执行器全自研**：双编码器设计，高精度控制
3. **触觉灵巧手**：6 阵列触觉传感器，行业领先
4. **最开放的平台**：全 ROS 支持，开发者生态友好
5. **硬件可靠性优先**：从康复医疗领域继承的可靠性标准

### 需关注
- 不自研 VLA 大模型，AI 能力依赖合作伙伴
- 品牌知名度在中国以外较低
- 定价较高（GR-1 约 $15-17 万）
- GR-2 量产进度待观察（目标 2026 年）
