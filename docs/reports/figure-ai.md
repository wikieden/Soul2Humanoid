## 2. 总体战略愿景（Master Plan）

### 战略选择
不走“为机器人改造环境”的路线，而是**“为人类环境设计人形机器人”**。一个通用的人形形态（两条手臂、两条腿、双手、屏幕面部）可以服务数百万种任务，而非为每种任务造一种专用机器人。

### 三阶段主计划
1. 打造功能完整的机电一体化人形机器人
2. 实现类人操作能力
3. 将人形机器人整合进劳动力

### 三大长期市场机会

| 市场 | 规模 | 特点 |
|------|------|------|
| **体力劳动** | 全球 GDP 的 50%（约 $42T/年） | 结构化，变化少 |
| **家庭消费** | 全球 23 亿户家庭，7 亿老龄化人口 | 非结构化，变化多 |
| **外太空** | 太空探索与建造新世界 | 极端环境 |

**首个落地场景**：制造、物流、仓储、零售（劳动力短缺最严重的领域）。

**明确排除**：军事/国防应用，以及任何需要伤害人类的角色。

## 4. AI 系统：Helix 架构演进

### Helix V1（2025.02）— 上半身通才 VLA

**核心突破**：首个能直接控制完整人形上半身的 Vision-Language-Action 模型。

**关键特性**：
- 单组神经网络权重学会所有行为（无需任务特定微调）
- 35 自由度上半身控制（手腕、躯干、头部、单指）
- 零样本多机器人协作（两个机器人共用同一套权重协作）
- "拿起任何东西"能力：对数千种从未见过的物品通过自然语言指令即可操作
- 完全在嵌入式低功耗 GPU 上实时运行（双 GPU 异步部署）

**训练数据**：约 500 小时高质量遥操作数据，使用 VLM 自动生成 hindsight 指令。

### Helix 02（2026.01）— 全身自主 Loco-Manipulation

**核心突破**：将控制从上半身扩展到**全身**（行走 + 操作 + 平衡），实现首个持续数分钟的端到端自主 loco-manipulation 任务。

## 5. 数据战略：Project Go-Big

**核心理念**：机器人领域缺乏类似 ImageNet、Wikipedia、YouTube 的大规模预训练数据集。人形机器人因运动学和视角与人类相似，可直接从日常人类视频中迁移知识。

### 两个关键进展（2025.09）

| 进展 | 说明 |
|------|------|
| **互联网规模预训练** | 与 Brookfield（管理 $1T 资产，>10万套住宅）战略合作，在真实住宅环境中大规模采集人类目标导向行为 |
| **零样本人类视频迁移** | 仅用第一人称人类视频（零机器人演示）训练 Helix，实现语音导航（"走到厨房桌子那里"）。人形机器人领域首次实现完全从人类视频到机器人端到端控制迁移 |

**关键结果**：
- Speech-to-nav：自然语言命令 → 像素到闭环控制 → 复杂家庭环境导航
- 单一统一模型：同一个 Helix 网络同时输出灵巧操作和导航指令
- 无需机器人特定数据或训练

## 6. 制造与规模化：BotQ

**定位**：Figure 的专用人形机器人高产量制造工厂

| 指标 | 目标 |
|------|------|
| 首代产线年产能 | 12,000 台 |
| 四年总产量目标 | 100,000 台 |
| 供应链扩展能力 | 100,000 台机器人 / 3,000,000 个执行器 |

**核心策略**：
- **垂直整合**：执行器、手部、电池、最终组装全部自产
- **工艺转型**：从 CNC 转向压铸、注塑、金属注射成型、冲压（零件制造时间从一周缩短至 <20 秒）
- **软件基础设施**：自研 MES（制造执行系统）+ PLM + ERP + WMS
- **机器人造机器人**：用 Figure 人形机器人参与自身装配线和物料搬运，无需笨重固定的传送带

## 8. 核心逻辑总结

Figure AI 的技术路线呈现出清晰的 **"软硬件协同、数据飞轮驱动"** 特征：

### 1. AI 优先设计
Figure 03 的硬件完全围绕 Helix 的感知和控制需求设计（掌部相机、触觉传感器、低延迟视觉系统）。不是先造机器人再配 AI，而是 AI 需要什么，硬件就提供什么。

### 2. 数据闭环逐级跃升
```
遥操作数据（500h）
    ↓
人体运动数据（1000h+）
    ↓
互联网规模人类视频（Project Go-Big，Brookfield 住宅环境）
```

### 3. 三层时序分层架构
- **System 2**：语义/慢速（7Hz）→ "做什么"
- **System 1**：运动/中速（200Hz）→ "怎么做"
- **System 0**：执行/实时（1kHz）→ "稳不稳"

既保证高层智能，又保证底层实时性。

### 4. 量产前置
不同于许多机器人公司先做原型再考虑制造，Figure 从 Figure 03 开始就将可制造性作为核心设计约束。零件数量大幅削减，工艺从 CNC 转向模具化。

### 5. 场景递进策略

![Scenario Progression../assets/figure-ai/scenario-progression.svg)

```
商业物流（结构化） → 家庭环境（非结构化）
```
通过解决更难的家庭场景，自然覆盖更简单的商业场景。

### 6. 最终目标
构建一个 **"通用具身智能平台"**：
- 以**人形**为通用接口
- 以 **Helix** 为通用 AI 系统
- 以 **BotQ** 为量产基础设施
- 让机器人像人类一样在真实世界中**学习、适应和劳动**

## 9. 数据战略深度拆解：从遥操作到自主飞轮

> 本章节基于 2026 年 6 月最新动态（BotQ 量产、Helix 02 全身控制、Project Go-Big 住宅数据）进行专项分析。

### 9.1 Figure 的数据采集演进路径

Figure 的数据策略经历了清晰的三个阶段演进，与行业主流范式高度一致：

```
Phase 1（2024-2025.02）：高质量遥操作奠基
    └─ 500h 高精度遥操作数据训练 Helix V1
    └─ 关键点：直接控制、实时反馈、任务多样性

Phase 2（2025.03-2025.09）：规模化与多源融合
    └─ BotQ 工厂建立，目标年产 12,000 台
    └─ Project Go-Big：与 Brookfield 合作，进入真实住宅
    └─ 零样本人类视频迁移突破

Phase 3（2025.10-2026）：自主数据飞轮
    └─ Helix 02 全身自主操作 → 机器人自己生成训练数据
    └─ 舰队学习：350+ 机器人同时采集、同时训练
    └─ 边际成本趋近于零
```

### 9.2 核心方法：舰队遥操作 + 自主增强

Figure 没有选择昂贵的 Ego+MoCap+手套方案，而是走了**"舰队化低成本遥操作 → 自主飞轮"**的路线：

| 维度 | Figure 策略 | 与行业对比 |
|------|------------|-----------|
| **采集方式** | VR/遥操作舰队（350+ 机器人） | 非动捕室，可扩展 |
| **单条成本** | ~$5-20（ALOHA 级别） | 远低于 $50-100 的动捕方案 |
| **数据规模** | 目标：数十亿条操作记录 | 与 Tesla FSD 数据闭环对标 |
| **质量保障** | BotQ 工厂标准化 + 实时 VLM 校验 | 量产一致性 > 实验室精度 |
| **增量策略** | 自主重试 + LLM 纠错 + 人类视频迁移 | 三重放大效应 |

### 9.3 BotQ：制造即数据采集

Figure 的 BotQ 工厂不仅是制造中心，更是**数据采集中心**：

**硬件基础设施**：
- 24× 产能提升（120 天内）：从原型速度到 1 台/小时
- 350+ 机器人同时在工厂内运行、测试、采集数据
- 10 Gbps mmWave 无线数据卸载：每台机器人每天可上传 TB 级数据

**数据飞轮机制**：
```
机器人出厂测试 → 发现问题 → 遥操作修正 → 生成新训练数据
    ↑                                              ↓
    └──────── 模型更新后部署回机器人 ←──────────────┘
```

**关键洞察**：Figure 将"制造测试"本身转化为数据采集过程。每台机器人在出厂前的测试运行，都在为下一代模型贡献数据。

### 9.4 Project Go-Big：住宅环境的互联网规模数据

与 Brookfield 的合作是 Figure 数据战略的关键差异化：

| 合作方 | Brookfield Asset Management |
|--------|---------------------------|
| 管理资产 | $1 万亿+ |
| 住宅规模 | >10 万套住宅单元 |
| 数据价值 | 真实家庭环境的长周期人类行为 |

**技术突破**：
- **零样本人类视频迁移**：仅用第一人称人类视频（无机器人演示）训练 Helix
- **语音导航**："走到厨房桌子那里"→ 像素级闭环控制
- **单一统一模型**：同一个 Helix 网络同时输出操作 + 导航

**战略意义**：住宅环境比工厂/仓库**非结构化 10 倍以上**，掌握住宅数据 = 掌握通用 AI 的制高点。

### 9.5 Helix 02：从数据采集者到数据生产者

Helix 02 的全身自主能力标志着 Figure 进入**自主数据生成**阶段：

| 能力 | 数据价值 |
|------|---------|
| 4 分钟连续自主洗碗机装卸（61 个动作） | 零人工标注的完整任务链 |
| 失败自动重试 | 自动生成负面样本 + 正面修正样本 |
| 全身协调（臀/脚作为工具） | 传统遥操作难以覆盖的新颖行为 |
| 精细操作（药丸、注射器） | 高价值、高难度的稀缺数据 |

**自主数据飞轮公式**：
```
自主操作时间 ↑ → 数据采集量 ↑ → 模型能力 ↑ → 自主操作时间 ↑↑
```

### 9.6 Figure 数据战略的启示

1. **规模 > 精度**：350 台低成本遥操作机器人 > 1 套高精度动捕室
2. **场景层级**：物流（结构化）→ 住宅（非结构化），后者数据价值指数级更高
3. **制造即数据**：将量产过程本身嵌入数据飞轮
4. **自主是终点**：从人类遥操作 → 人类视频迁移 → 自主生成，边际成本递减至零
5. **数据是护城河**：$390 亿估值中，数据飞轮能力占比可能超过硬件本身
