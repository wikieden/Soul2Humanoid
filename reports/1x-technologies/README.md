## 2. 硬件产品

| 参数 | 数值 |
|------|------|

| **体重** | 30 kg (66 lbs) |
| **行走速度** | 1.4 m/s |

| **手臂载荷** | 8 kg (18 lbs) |
| **提拉能力** | 70 kg (154 lbs) |
| **搬运能力** | 25 kg (55 lbs) |
| **续航** | 4 小时 |
| **快速充电** | 6 分钟充 1 小时续航 |
| **噪音水平** | 22 dB（比现代冰箱更安静） |
| **计算平台** | 1X NEO Cortex（基于 Nvidia Jetson Thor） |

| **通信** | WiFi、蓝牙、5G |
| **防护等级** | 手部 IP68（可潜水），身体 IP44（防溅） |

### 2.2 独特硬件设计：肌腱驱动（Tendon-Driven）

1X 最核心的硬件创新是 **Tendon Drive（肌腱驱动）** 执行器：

| 特性 | 说明 |
|------|------|
| **驱动方式** | 类似人类肌腱的柔性传动，非传统齿轮/谐波减速器 |
| **扭矩精度** | 2% |
| **反向可驱动性** | 95%（高 compliance，碰撞时安全） |
| **重复精度** | 0.1 mm |
| **标称寿命** | 2,000,000 次循环（1 天可更换服务） |
| **峰值寿命** | 100,000 次循环（3 倍标称负载） |
| **听觉噪音** | 22 dB（极低） |

**为什么肌腱驱动适合家用？**
- **安全性高**：高反向可驱动性意味着遇到阻力时会自然"让开"，不会伤到人
- **安静**：22 dB 的噪音水平不会打扰日常生活
- **柔和**：低惯性运动适合与人类共处一室
- **夹 pinch 防护**：所有关节从外部不可触及，表面无夹点

### 2.3 软件身体（Soft Body）

- 全身包裹**定制 3D 晶格聚合物结构**
- 可变形、可缓冲碰撞
- 外衣和鞋子可机洗（尼龙材质）
- 设计哲学：**"Cozy Design"** — 让机器人成为家居环境的一部分

## 3. AI/软件架构

### 3.1 Redwood AI — 通用家务模型

Redwood 是 1X 自研的 **VLA（Vision-Language-Action）模型**，专为家用场景设计。

**核心能力**：
- **移动操作联合控制**：Redwood 是首批将移动（locomotion）与操作（manipulation）联合控制的 VLA 之一
  - 机器人可以在操作时调整身体姿态（如倾斜、支撑）以最大化抓取成功率
- **从失败中学习**：训练数据同时包含成功和失败案例，NEO 从每次交互中获取上下文
- **泛化能力**：可以处理从未见过的物体，即使出现在全新位置
- **语言意图预测**：集成离线语言模型，实时从语音和对话上下文中预测用户意图

**Redwood AI 的分层架构**：

| 模块 | 功能 |
|------|------|
| **视觉理解** | 理解家庭环境中的物体、空间关系和人类活动 |
| **语言理解** | 通过内置 LLM 理解自然语言指令 |
| **动作生成** | 生成移动 + 操作的联合动作策略 |
| **记忆系统** | 保留信息以个性化用户体验 |

![1X NEO System Architecture](../../assets/1x-neo-system-architecture.svg)

**图**：1X NEO 系统架构 — 多模态输入经 Redwood VLA 处理，World Model 提供物理预测，内置 LLM 处理语言交互，最终通过肌腱驱动执行器输出安全动作。

### 3.2 1X World Model — 世界模型

1X World Model 是 NEO 的**认知核心**，是一个基于物理的视频生成模型。

**功能**：
- **动作结果预测**：在真实执行前，"想象"或"幻觉"出 NEO 动作的结果
- **未见任务泛化**：能够泛化到从未见过的任务，用户只需用自然语言描述
- **自主学习**：Ask NEO anything and watch it attempt the task entirely autonomously

**技术本质**：
-  grounded in physics 的视频模型
- 允许机器人在仿真中试错，然后迁移到真实世界
- 类似人类的心理模拟能力

### 3.3 专家模式（Expert Mode）

NEO 的**数据获取策略**非常有特色：

- **默认自主运行**：NEO 出厂即具备基础自主能力
- **专家远程指导**：对于 NEO 不会的任务，用户可以预约 1X Expert 远程遥控指导
- **边做边学**：Expert 在遥控完成任务的同时，NEO 记录数据并学习
- **逐步解锁能力**：随着使用时间增长，NEO 不断解锁新技能

## 5. 应用场景与商业化

### 5.1 核心场景：家庭

NEO 明确瞄准**家用市场**，而非工业：

- 日常家务（清洁、整理、洗碗）
- 陪伴互动（对话、讲故事、游戏）
- 辅助照护（对老人、儿童的支持）
- 物品递送（在家中移动物品）

### 5.2 商业模式

- **预购定金**：$200 定金
- **订阅模式**：提供订阅选项（具体价格未公开）

### 5.3 与 Figure AI / Tesla 的差异

| 维度 | 1X Technologies | Figure AI | Tesla |
|------|----------------|-----------|-------|
| **目标市场** | 家庭（C 端） | 商业→家庭（B→C） | 工厂→家庭（B→C） |
| **硬件特色** | 肌腱驱动、软体、超安静 | 工业级精密、无线充 | 汽车级制造、规模化 |
| **AI 特色** | World Model + 专家学习 | Helix VLA 端到端 | FSD 神经网络迁移 |
| **安全理念** | 物理本质安全（肌腱+软体） | 软件安全层 | Guardian Network |
| **数据策略** | 真实家庭 + 专家遥操作 | BotQ 自主生成 | 车队数据飞轮 |
| **投资方** | OpenAI | Microsoft、NVIDIA 等 | 自有现金流 |
