## 1. 公司概况

### 1.1 历史沿革

Boston Dynamics 的故事始于 **1992 年**，由 **Marc Raibert** 从 MIT Leg Laboratory 分离后创立。公司早期以 DARPA 资助的军事机器人项目起家，先后开发了 BigDog（2004）、LS3（2010）、PETMAN、WildCat（2011）、SandFlea（2012）、RHex（2007）、RiSE（2006）等研究型机器人，奠定了在足式机器人动态平衡与控制领域的全球领导地位。

**Atlas 项目脉络**：
- **2013 年**：DARPA 资助下推出第一代液压 Atlas，定位为搜救机器人研究平台
- **2016-2023 年**：液压版 Atlas（HD Atlas）持续迭代，以跑酷、后空翻、舞蹈等展示全身动态控制能力
- **2024 年 4 月**：宣布退役液压 Atlas，发布**全电动 Atlas**，标志着从研究走向商业化
- **2026 年 1 月**：在 CES 2026 上发布**产品版 Atlas**，正式启动量产与工业交付

### 1.2 资本沿革与 Hyundai 收购

Boston Dynamics 经历了三轮重要的所有权变更：

| 时间 | 事件 | 影响 |
|------|------|------|
| 2013 | 被 **Google**（Alphabet X）收购 | 获得充裕研发资金，远离军事合同，转向民用研究 |
| 2017 | 被 **SoftBank** 收购 | 推动商业化尝试，Spot 开始面向企业销售 |
| 2021 | 被 **Hyundai Motor Group** 以约 11 亿美元收购 80% 股权（后增持） | 获得汽车制造供应链、量产能力和全球渠道 |

**Hyundai 收购后的关键变化**：
- **供应链整合**：2026 年 CES 宣布 **Hyundai Mobis** 成为 Atlas 执行器（actuator）的战略供应商
- **制造基地**：Hyundai 在美国投资 **260 亿美元**，规划建设年产 **30,000 台机器人**的新工厂
- **第一客户**：Hyundai 自身成为 Atlas 的首批部署客户，2025 年已在乔治亚州 Metaplant 实地测试
- **战略升级**：Hyundai 在 CES 发布 **AI Robotics Strategy**，以 Boston Dynamics 为核心推进"以人为本的机器人时代"

## 2. 硬件演进：从液压到电动

### 2.1 液压版 Atlas → 电动版 Atlas 的技术路线转变

**液压时代的遗产（2013–2024）**：
- 液压 Atlas 以 **28 个液压关节** 实现了极强的动态运动能力（后空翻、跑酷、舞蹈）
- 核心贡献在于验证了**全身控制算法（Whole-Body Control）**、**模型预测控制（MPC）**的可行性
- **致命缺陷**：液压系统笨重、噪音大、维护复杂、能耗高、漏油风险，完全无法商业化

**电动化的决定性转折（2024 年起）**：
- **2024 年 4 月**，Boston Dynamics 宣布退役液压 Atlas，推出**全电动 Atlas**
- 电动化不仅是动力源更换，而是**彻底的重置**：
  - **简化复杂度**：去掉液压管路、泵站，大幅降低 unique parts 数量
  - **更安静的运行与更高的能效**
  - **可维护性**：所有 limbs 可在现场 **5 分钟内**更换
  - **安全性**：消除高压液压油泄漏风险，更适合人机共存环境

### 2.2 新版 Atlas（产品版）规格参数

| 参数 | 数值 |
|------|------|
| **身高** | 1.9 m（6.2 ft） |
| **体重** | 90 kg（198 lbs） |
| **自由度（DoF）** | 56 |
| **臂展** | 2.3 m（7.5 ft） |
| **关节运动范围** | 连续旋转（无机械限位） |
| **瞬时负载** | 50 kg（110 lbs） |
| **持续负载** | 30 kg（66 lbs） |
| **电池续航** | 4 小时（典型工况） |
| **自主换电时间** | < 3 分钟 |
| **防护等级** | IP67（可水洗/防尘） |
| **工作温度** | -20°C ~ 40°C |
| **传感系统** | 头部 HDR 立体相机对 + 触觉传感器 + 360° 环境感知 |
| **充电输入** | 110V / 220V 标准市电 |

**关键设计哲学**：
- **超越人类运动范围**：关节可连续旋转，能实现人类无法完成的动作（如躯干 180 度旋转）
- **汽车级供应链**：所有部件设计兼容 automotive supply chain，为规模化降本铺路
- **现场可服务性**：强调"可清洁、可维修、可升级"

### 2.3 产品矩阵：Spot / Stretch / Atlas / Orbit

| 产品 | 形态 | 核心场景 | 与 Atlas 的协同 |
|------|------|----------|-----------------|
| **Spot** | 四足 | 工业巡检、安全响应 | 2,000+ 客户部署，积累 unstructured environment  autonomy 经验 |
| **Stretch** | 轮式 + 机械臂 | 仓储搬运、集装箱卸货 | 共享 warehouse automation 客户群和软件栈 |
| **Atlas** | 双足人形 | 制造零件排序、机器看护 | 补足需要人形适配、高灵活性的场景 |
| **Orbit** | 软件平台 | Fleet 管理、数字孪生 | 统一调度 Spot/Stretch/Atlas |

**战略意图**：先用 Spot/Stretch 教育市场、建立客户信任与数字化基础设施，再引入 Atlas 解决更复杂的类人任务。

## 3. AI/软件架构

### 3.1 控制方法：MPC + RL + 神经网络的混合架构

**（1）传统基石：模型预测控制（MPC）**
- 数十年来，Boston Dynamics 的 legged robots 依赖 **MPC** 进行实时轨迹优化
- MPC 的优势在于**可解释性、可调试性**，工程师可以通过调整目标函数和约束来精细调节行为
- 液压 Atlas 的跑酷、舞蹈，以及 Spot 早期版本的核心平衡控制，均基于 MPC

**（2）强化学习（RL）的引入**
- 面对真实世界中难以建模的场景（湿滑地面、不规则障碍物），纯 MPC 需要并行运行数十个实例
- 2024 年起，Spot 的 locomotion 系统引入 **RL 策略网络**：
  - 在仿真中运行 **百万级** 模拟场景训练策略
  - RL 策略替代了 MPC 的"选择器"，将并行计算降为单次推理
  - Spot 在湿滑/极端地形上的跌倒率显著下降
- Atlas 的行走/跑步/爬行等自然步态同样使用了 **RL 训练 pipeline**

**（3）大型行为模型（LBM）用于全身操纵**
- 在与 TRI 的合作中，Atlas 采用了 **4.5 亿参数的 Diffusion Transformer** 架构
- 使用 **Flow Matching Loss** 训练，控制频率 **30Hz**
- 输入：头部双目相机图像 + 本体感受 + 自然语言指令
- 输出：未来 1.6 秒的动作轨迹块（length 48），涵盖双臂、双手、颈部、躯干、双脚的全 body pose
- **关键突破**：单一策略即可完成从简单 pick-and-place 到系绳、铺桌布、翻凳子、搬运轮胎等长时程任务

### 3.2 分层混合架构

| 层级 | 方法 | 负责能力 |
|------|------|----------|
| **底层平衡与步态** | MPC + RL 策略 | 实时稳定、防滑、动态响应 |
| **中层运动规划** | 优化 + 学习 | 全身协调、避障、自碰撞避免 |
| **高层感知与决策** | 视觉基础模型 + VLA | 物体检测、语义理解、任务推理 |
| **操纵执行** | Diffusion Transformer（LBM） | 端到端灵巧操作、语言条件化行为 |

Boston Dynamics 的技术路线**并非端到端黑箱**，而是：
- 保留 MPC 作为可信赖的物理基础
- 在 MPC 难以覆盖的"边缘案例"上引入学习
- 高层行为逐渐向**数据驱动、语言条件化**迁移

### 3.3 感知与决策 AI 升级

**感知系统（Perception）**：
- **2D 感知**：轻量级网络实时检测物体、边界框、关键点
- **3D 定位**：基于关键点的 fixture localization，结合运动学里程计
- **物体姿态跟踪（SuperTracker）**：融合运动学、视觉、力觉；使用大规模合成数据训练的模型对 CAD 模型 zero-shot 泛化
- **视觉基础模型**：开放集物体检测赋予语义理解能力

**决策与自主性**：
- **三种控制模式**：自主模式、VR 遥操作、平板遥控
- **无围栏作业（Fenceless Guarding）**：onboard 安全系统检测人和车辆
- **Orbit 集成**：通过 MES/WMS/条码扫描器接入工厂信息流
- **Fleet 学习**：一台 Atlas 学会的新任务，可即时部署至整个 fleet

### 3.4 关键合作

**Toyota Research Institute (TRI)**：
- **2025 年 2 月**：BD 与 TRI 联合发表论文，Atlas 使用单一 Diffusion Transformer 策略完成复杂长程操作
- TRI 提供灵巧操作方面的深厚积累

**Google DeepMind**：
- BD AI 负责人 Alberto Rodriguez 公开表示有合作
- 方向可能是将 DeepMind 的 VLA / 语言模型能力集成到 Atlas 行为系统中

## 4. 数据策略

| 数据来源 | 作用 | 说明 |
|----------|------|------|
| **人类遥操作** | 高质量种子数据 | 工程师通过 VR/平板遥控 Atlas 完成任务 |
| **仿真生成** | 大规模低成本数据 | Isaac Sim / MuJoCo 中生成数百万场景 |
| **真实世界自主 Episode** | 闭环增强 | 自主运行，成功/失败数据回传 |
| **合成数据渲染** | 感知模型训练 | CAD 模型渲染，用于 SuperTracker zero-shot 姿态估计 |
| **Fleet 数据共享** | 规模化扩展 | Spot 2,000+ 部署的环境数据用于 Atlas 感知预训练 |

## 5. 商业化路径与竞争格局

| 维度 | Boston Dynamics | Figure AI | Tesla |
|------|----------------|-----------|-------|
| **核心优势** | 20+ 年动态控制积累、MPC+RL 混合可靠性、Hyundai 供应链 | AI-first 硬件设计、Helix VLA 端到端、快速迭代 | FSD 技术迁移、规模化制造、数据飞轮 |
| **技术路线** | 分层混合（MPC + RL + VLA） | 端到端 VLA | 端到端神经网络（FSD 移植） |
| **产品形态** | 工业级人形 + 四足 + 轮式臂 | 商业/家庭人形 | 通用人形 |
| **市场策略** | B2B 工业优先，Spot 已验证市场 | B2B 制造起步，长期目标家庭 | 工厂 + 家庭 |
| **数据优势** | Spot 2,000+ 部署的真实世界数据 | BotQ 大规模自主数据生成 | 数百万辆车的 FSD 数据 |
| **制造优势** | Hyundai 汽车级供应链 | 全新搭建供应链 | Tesla 超级工厂 |
