## 3. AI/软件架构

### 3.1 控制方法：强化学习 + 模仿学习

**（1）强化学习（RL）驱动的运动控制**
- 使用 RL 训练行走、跑步、舞蹈等运动技能
- 春晚《秧BOT》中的高动态舞蹈动作即由 RL 训练实现
- 在仿真环境中训练，迁移到真实机器人

**（2）模仿学习（Imitation Learning）**
- 通过动作捕捉或遥操作获取人类动作数据
- 训练机器人模仿人类动作
- 适用于舞蹈、体操等展示性动作

**（3）UniFolm（Unified Robot Large Model）**
- 宇树自研的统一机器人大模型
- 目标是实现跨机器人形态（四足 + 人形）的通用控制
- 目前公开信息较少，处于早期阶段

![Unitree RL Pipeline](../../assets/unitree-rl-pipeline.svg)

## 4. 成本控制秘诀

宇树能做到低成本的几个关键因素：

1. **自研关节电机**：掌握核心零部件，避免进口高价电机
2. **四足机器人积累**：多年机器狗量产经验，供应链成熟
3. **中国制造优势**：依托国内完善的电子制造供应链
4. **简化设计**：G1 采用相对简化的结构（如 5 自由度手臂）
5. **规模效应**：四足机器人已出货数千台，摊薄研发成本
