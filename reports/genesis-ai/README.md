## 二、产品：GENE-26.5

### 核心宣称

Genesis AI 将 GENE-26.5 定位为**全栈人形机器人解决方案**，目标是在感知、推理、操作三个维度同时达到接近人类水平。

```
┌─────────────────────────────────────────┐
│  GENE-26.5 全栈架构（推测）               │
├─────────────────────────────────────────┤
│  认知层：大语言模型 + 世界模型             │  ← 任务理解、推理、规划
├─────────────────────────────────────────┤
│  感知层：多模态传感器融合                  │  ← 视觉、触觉、力觉
├─────────────────────────────────────────┤
│  操作层：Genesis Hand 1.0（Wuji Tech）    │  ← 人级灵巧度
├─────────────────────────────────────────┤
│  移动层：双足/轮式（推测）                 │  ← 环境导航
└─────────────────────────────────────────┘
```

### Genesis Hand 1.0（硬件合作）

- **合作方**：Wuji Tech（无极科技）
- **特点**：专为人级灵巧度设计的末端执行器
- **能力**：在演示中展示了处理鸡蛋等精细物体的能力（来源：Humanoids Daily 报道配图）
- **性质**：Wuji Tech 提供硬件平台，Genesis AI 提供软件/AI 栈
